# abdullahPOS

نظام نقاط بيع لويندوز، يعمل بدون إنترنت، عربي بالكامل، ومتوافق مع الفوترة الإلكترونية (زاتكا).

هذا المستودع لملفات التثبيت فقط.

## التحميل

حمّل آخر نسخة من صفحة [Releases](../../releases/latest)، الملف `abdullahPOS-Setup-<الإصدار>.exe`.

## التثبيت والتحديث

- يعمل على ويندوز 10 و11 (64 بت)، ولا يحتاج تثبيت أي برنامج آخر.
- للتحديث: ثبّت النسخة الجديدة فوق القديمة مباشرة. البيانات محفوظة في `C:\ProgramData\abdullahPOS\` ولا تتأثر، وتحديث قاعدة البيانات يتم تلقائيًا عند أول تشغيل.
- يُنصح بنسخ مجلد `C:\ProgramData\abdullahPOS\Data` احتياطًا قبل أي تحديث.
- إذا ظهرت رسالة «Windows protected your PC»: اضغط **More info** ثم **Run anyway**.
